# Kit de análise Unity para Codex Cloud

Abra o [prompt completo](PROMPT-CODEX-CLOUD.md) e use o conteúdo como pedido em uma tarefa Codex Cloud. Os anexos estão na [release privada v1.135-analysis](https://github.com/kimlherme/unity-a56-v1135-analysis/releases/tag/v1.135-analysis).

- O kit ZIP permite começar pela descompilação das DLLs C# e pela leitura do catálogo.
- Os quatro ZIPs de bundles são independentes e contêm os 431 arquivos Windows. Extraia todos os arquivos na mesma raiz para análise de assets. Confira espaço antes de baixar o complemento.
- Valide os anexos com o arquivo SHA256SUMS.txt da release. Dentro do kit estão os manifestos de cada arquivo original.
- O acesso aos anexos exige autorização para este repositório privado. A tarefa Cloud deve confirmar que consegue ler a release pelo gh antes de buscar os arquivos.

Veja [o escopo do kit](ESCOPO.txt) para tamanhos descompactados e conteúdo.
